# StrataStrach-solutions 

Este repositorio contiene mis **soluciones a ejercicios de SQL de StrataScratch**, enfocadas en la categoría **Easy**.  
Cada ejercicio está resuelto en un archivo individual, con consultas corregidas, comentarios y mejoras progresivas.


El objetivo de este repo es **practicar SQL de forma sistemática** y dejar un registro claro de las soluciones.

# 🧠 Cómo usar este repositorio

1. Entra a la carpeta 
2. Selecciona el ejercicio que quieras revisar
3. Abre el archivo 
4. Revisa comentarios y correcciones aplicadas
